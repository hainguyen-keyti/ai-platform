Done means:

1. On a phone the open list is a step in the tab's history: Back closes it and stays in the app;
   closing it any other way (Close, a row, New chat, Escape, "chat" in the nav, a wider window,
   the gallery) takes that step back out, so the next Back does what it did before the list
   opened. "chat" in the nav closes the list
2. The list says "No conversations yet." / "Chưa có cuộc trò chuyện nào." when it is empty and
   "No conversation matches." / "Không tìm thấy cuộc trò chuyện nào." when a search finds nothing,
   only once the list has answered
3. The provider select is named "Provider" / "Nhà cung cấp", with or without a conversation open
   (the lock sentence stays its title)
4. Every visible text and placeholder on the login page, the chat, the list, the typing bubble, the
   file card and the gallery meets 4.5:1 (3:1 for large text): slate-500 on white (4.76) and
   slate-50 (4.55), slate-600 on a list row and the badge (6.92 on slate-100), placeholders
   slate-500
